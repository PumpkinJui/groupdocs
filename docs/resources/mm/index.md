## 最新版本更新日志 - 1.0 - Snapshot 7

> 本文合并了 Exp 和 Snapshot 版本的更新日志，并且抹去了技术性的相关更新，如果您对此感兴趣，请见更新日志页面。

密室杀手中最恐怖的是什么？好吧，除了恐怖的杀手和侦探恐怖的弓法之外，还包括地图中一大堆的史蒂夫头颅！史蒂夫北极熊、史蒂夫人头树等诡异装饰充满了地图！而今天，我们正式实现了这些头颅的替换工作，并全面改进了许多处细节的游玩体验。

本周的更新还修复了上周出现的一些问题，并更新了 4 张新地图。

一起来看看本周的更新吧，祝你躲过杀手的追击！

1.0 - Snapshot 7b 更新：修复了地图默认被开启为禁止多人的问题，并修复了头颅朝向无法正确显示，部分头颅贴图出错的问题。

### 自定义头颅

- 隆重推出——地图自定义头颅替换工程！
- 经过我们的管理群团队的几位成员（绿叶、南瓜汁、文雨）没日没夜的努力，我们将原地图中的绝大多数自定义头颅都应用在了基岩版
- 使用自定义方块技术制作的自定义头颅替换了所有的玩家头颅
- 现在你再也不会看到人头树了！
- 备注：因为自定义头颅的工作量极大，我们一共向游戏添加了 340 种头颅，合计在游戏内应用了超过 1000 个头颅，因此目前还存在一些问题，包括贴图错误、头颅替换遗漏等情况，预计会在未来的 1~3 个版本内彻底解决

### 地图

- 更新了地图 Widow’s Den 的翻译为 黑寡妇巢穴，和 Hypixel 最新的翻译一致
- 现在若地图未完成适配，会在开始游戏前提示玩家
- 现在所有地图都会默认应用岩浆和溺水效果
- 现在地图游轮允许对活板门进行交互
- 现在地图总部允许对橡木门进行交互
- 实装了地图水族馆的鲨鱼陷阱
- 新增地图港口小镇 V1、阴森庄园 V1、阴森庄园 V2
- 略微扩大了地图高坠塔的范围
- 对多张地图的多处细节都进行了修改和修复
- 新增地图水上度假村

### 设置

- 现在游戏开始后会在玩家的物品栏中新增一个设置物品，以便管理员等玩家可以在游戏内进行设置
- 更改了默认的信息板最后一行黄字为“YZBWDLT”，以确保英语下信息板的字体可以正常显示为 Mojangles
- 现在可以通过设置开启一张随机地图了
- 现在在玩家死亡后，会直接打开设置页面，并在设置内内置了 传送到 设置项
- 新增了 3 项设置：侦探弓冷却、最大选取金点数、飞刀冷却

### 最低版本需求

- 因为添加了 16 向旋转的头颅，现在提高了游戏最低版本需求为 26.40

### 杀手飞刀

- #29 为手机版的杀手飞刀添加了一个交互按钮，现在不必长按也能触发杀手飞刀了

### 神秘药水

- 更换了 5 种药水的贴图，现在使用更加鲜艳的颜色，可以轻易分辨不同药水了
- 现在神秘药水的迅捷效果结束后，不再会彻底顶掉杀手的迅捷效果

### 金锭生成

- 现在金锭生成不再只考虑 xz 方向上的距离，并略微增大了金点检查半径

### 漏洞修复

- 修复了多处英语翻译错误或不清的地方
- 修复了系统会在常加载区域加载完毕之前就尝试新建新系统，导致系统无法创建，游戏直接卡死的问题
- 现在游戏内可以开启灵动视效（Vibrant Visuals）和光线追踪（Ray Tracing）了
- 修复了存活玩家判断错误而导致的一系列问题
- 修复了矿车可能会被破坏的问题，现在即便被破坏也能迅速恢复
- 修复了按钮在被按下后尝试交互仍然能触发事件的问题
