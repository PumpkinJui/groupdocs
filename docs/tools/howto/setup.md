# Minecraft 国际基岩版常用设置

现在你安装了 Minecraft 国际基岩版。或许就可以直接开玩了吗？

是这样，但跟着下面的流程调整一些设置，可以让游戏体验更好一些。

影响体验和推荐修改的程度大概是这样，强烈建议 > 建议 & 重要 > 不重要 & 可以。

## 译名包

强烈建议使用译名包。

译名包，又称「基岩版译名修正」，是由原中文 Minecraft Wiki 行政员 FF98sha 维护的资源包，旨在根据 [Wiki 译名标准化](https://zh.minecraft.wiki/w/Minecraft_Wiki:%E8%AF%91%E5%90%8D%E6%A0%87%E5%87%86%E5%8C%96)修正基岩版不标准的翻译。

基岩版不标准的翻译又是什么东西？比如老版本的「老守卫者」「带有命令块的《我的世界》」「海角」，还有新版本的「潜声」「戳刺」「蓝色蛋」，虽然有改进（至少把之前的修了一部分），但也不是很多。这时，为了让中文译名能让中国人看懂，就需要这个译名包了。

你需要从本文档[常用网址](../urls/frequently_used)页面下载译名包，然后进行安装。安装可以参考本文档[教程](./import_mcx)。然后在「设置 - 全局资源」中选择「我的包」，点击译名包后选择「激活」，返回主界面即可。

此后的译名以安装译名包后的为准。

## 辅助功能

这里面最重要的是「隐藏式字幕」和「文本背景不透明度」两项。

隐藏式字幕建议开启。这个功能是从 Java 版来的，可以在屏幕上显示游戏内的声音。即使有耳机，这个功能也非常实用，可以快速分辨是什么样的声音，以及在哪个方位。

文本背景不透明度建议调为 0%，这样标题就不会带一个奇怪的灰色背景了。

如果在实际体验中发现末地天空闪来闪去，很影响体验，可以开启「隐藏天空闪烁效果」。这样末地的天空就不会闪烁了，雷暴天气也是这样。

新版本加入的「方块淡出」以及「玩家和生物淡出」，会在玩家接近透明方块、其他玩家和生物时让它们淡化，这样就不会阻挡视野了。如果不喜欢这个效果，也可以关掉。

## 控制

这个没有什么必须改的项目，但会很影响所谓的「手感」。其中分成了三种操控方法，也就是「键盘和鼠标」「手柄」「触摸」。电脑键鼠操作改键盘和鼠标，手柄操作改手柄，手机触控改触摸。只改用的那个就可以了。

键盘和鼠标没什么可说的，可以根据喜好调调「视角灵敏度」这项，控制移动速度的，和鼠标的 DPI 功能差不多。

触摸的话，除了视角灵敏度以外，就有不少可以提一下的了。

- 老玩家很可能会更喜欢用「方向键移动 + 点击交互」的控制模式。「左手模式物品栏操作」交换左右触控，是左撇子离不开的设置（本人亲身体验）。此后还可以创建一个世界，进去在「自定义控制方案」自己微调各个组件的位置。
- 「自动跳跃」在遇到方块时自动跳跃，建议尝试一下再考虑要不要关。
- 如果顶部的三个按键容易点不到，可以调大「顶部按钮大小」。
- 如果创造模式挖得不够爽，可以关掉「延迟破坏方块」，注意这个挖得很快，不要挖到什么不能挖的东西。

## 通用

这里面有几个强烈建议改掉的项目。

强烈建议开启「允许使用移动数据进行在线游戏」。不开这个就只能在 Wi-Fi 环境下打游戏，除非没流量，否则应该没人想要这样的限制。

强烈建议关闭「仅允许受信任的皮肤」。如果它开着，进了服务器其他人的自定义皮肤就显示不出来了。

顺便一提，如果你希望自己的皮肤在制作的地图中被使用或被鸣谢，请将皮肤文件上传至「群文件-群成员皮肤」，并最好标注你更习惯于使用「粗壮」模型还是「纤细」模型。如果你希望自己的皮肤出现在网易版，请务必保证上传的皮肤为原创，否则可能被网易版强行改成默认皮肤（Steve 和 Alex 一类）。

强烈建议关闭「教程」。据说这个功能在世上存在的必要性不亚于阑尾。

## 视频

这个地方也没什么必须改的项目，而且更多取决于你的设备性能。

如果设备支持的话，可以尝试一下「光线追踪」和「灵动视效」，但这个功能在手机上联机耗电特别快。

可以把「渲染距离」适当调大，这样就能看得更远了。注意这里和世界设置中的「模拟距离」不一样，渲染距离影响看得多远，模拟距离影响到底有多少东西能动。

云、树叶和气泡柱这些随意。

手机上 UI 设置可以调成「经典」，个人认为更耐看，而且有些作者会喜欢在箱子里面摆个造型什么的。嫌小可以调回「携带版」。

关掉「隐藏纸娃娃」以后，可以在疾跑、潜行和游泳等状态下，在屏幕左上角显示一个你本人的皮肤。

「轮廓选择」算是比较建议开一下，方便确定到底选中的是哪个方块。

## 存储

这里需要强调一些关于存档和数据管理的事情。

不管什么设备，都强烈建议将存档及其他资源定期备份。这可以有效防止无意及有意的破坏；令人痛心地，这已经在个人存档和集体项目上经历过多次必要性验证。存档位置见[这篇文档](./import_mcx#存档位置)。

然后，在安卓手机上，下面这些非常重要。

首先，强烈建议将文件存储位置由「应用程序」改为「外部存储」。这样虽然在 Android 11 及以上访问也会受限，但至少存档还有导出的希望。如果选到了「应用程序」，没有 root 权限就完全不可能进入存档目录了。

之后，强烈建议在手机管家的垃圾清理中为 Minecraft 设置白名单。手机管家会把存档当垃圾清理掉，详见[这篇帖子](https://klpbbs.com/thread-26933-1-1.html)。已经令人痛心地证实，这一问题至少到国际基岩版 1.20.0 仍然存在。*如果你的手机没有「设置白名单」的功能，就把这件事牢牢记住，垃圾清理时把 Minecraft 手动取消勾选。*

最后，一定不要在存档文件全部导出前卸载 Minecraft，不管出于什么理由！无论存档在「应用程序」还是「外部存储」，卸载时系统都会全部删除。除非你不在意自己的存档，否则绝对不要这么做。

*每一句「令人痛心地」，都意味着本群至少有一名测试员因该原因彻底失去了自己的存档。*
